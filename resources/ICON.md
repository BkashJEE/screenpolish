# ScreenPolish icon assets

The app icon combines the product's three recognizable ideas: a recording
lens, the polished cursor, and click/zoom ripples. Its graphite and warm orange
finish follows ScreenPolish's existing dark interface palette.

- `icon-master.png` is the 1254 px source artwork with a transparent rounded
  mask. Preserve it when regenerating platform files.
- `icon.png` is the 1024 px Linux and macOS application icon.
- `icon-256.png` is used inside the editor and as its favicon.
- `icon.ico` contains 256, 128, 64, 48, 32, 24 and 16 px Windows entries.
- `tray.png` intentionally remains the simpler mark: detailed 3D artwork does
  not remain legible in a 16–32 px system tray slot.

The source artwork was created specifically for ScreenPolish from an original
prompt and then converted locally into the platform assets above. It contains
no third-party logo or copied product character.
