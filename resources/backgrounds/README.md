# Bundled backgrounds

- `omarchy.png`: Omarchy's Tokyo Night wallpaper, copied unchanged from the
  locally installed `/usr/share/omarchy/themes/tokyo-night/backgrounds/omarchy.png`.
  Upstream: https://github.com/basecamp/omarchy.

These are recording backgrounds; selecting them does not change the desktop theme.

Brand lettering is rendered separately, using bundled fonts so preview and export
do not depend on system fonts or network access:
- Omarchy: the installed `omarchy.ttf` font's U+E900 Omarchy wordmark glyph.
  This is an icon/wordmark font, not a general-purpose alphabet.
